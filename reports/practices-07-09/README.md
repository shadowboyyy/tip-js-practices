## Запуск вручную

В VS Code открыть корень `tip-js-practices`. В каждом новом терминале сначала убедиться, что открыт именно корень репозитория. Если зависимости ещё не установлены, из папки каждой практики выполнить `npm ci`.

Первый терминал — практика 7:

```bash
cd practice-07
npm run dev
```

Открыть http://127.0.0.1:5173/.

Второй терминал — API практики 8:

```bash
cd practice-08
npm run api
```

Третий терминал — интерфейс практики 8:

```bash
cd practice-08
npm run dev -- --port 5174
```

Открыть http://127.0.0.1:5174/. API работает на http://127.0.0.1:5505/api. Если здесь уже запущен сервер ПР6, остановить его через Ctrl+C в его терминале либо использовать другой порт API по инструкции README ПР8.

Четвёртый терминал — практика 9:

```bash
cd practice-09
npm start -- 5515
```

Открыть http://127.0.0.1:5515/api/tasks?priority=medium. Для отрицательного сценария варианта: http://127.0.0.1:5515/api/tasks?priority=medium&priority=medium.

Остановка каждого процесса — Ctrl+C в его терминале. При занятом порту интерфейса указать свободный: `npm run dev -- --port 5177`, затем открыть адрес с этим портом.

## Что показать на защите

В ПР7 создать задачу среднего приоритета: при начальном фильтре найдено станет пять вместо четырёх. Обновление страницы восстановит исходные данные.

В ПР8 повторить создание и показать POST 201, затем GET 200 во вкладке Сеть. После обновления страницы задача останется. После перезапуска процесса API вернутся исходные 12 задач.

В ПР9 показать фильтр medium и четыре id: 1, 10, 19, 28. Повтор priority даст 400, /api/tasks/2 — 404. Операции записи собственного сервера относятся к ПР10; у ПР9 разрешены GET, HEAD, OPTIONS.

Полные ответы на контрольные вопросы и таблицы ожидаемых и фактических результатов находятся в README каждой практики.
